== OpenShift Roadshow

During this 2 days, you will have the possibility to access to 2 different labs:

* **Beginner's lab:** A first introduction to OpenShift Virtualization focus on how a virtualization user can easily deploy VM via the OpenShift Console.
* **Advanced lab:** A more advanced guide focus on VM optimization and placement

*Feel free to follow the one you want.*


[WARNING]
====
Please, read attentively these different points before to start:


* **Point n°1:** The environments for these labs are generated on-demand and are not representative of reality. Indeed, for cost and automation reasons, these OpenShift Virtualization environments are "nested" and not supported in production. Performance may therefore be significantly affected.
* **Point n°2:** Please feel free to ask any questions. Some aspects are not covered in these labs but can be demonstrated.
* **Point n°3:** Please make sure you use the login details you have been provided with.
* **Point n°4:** Lab instuctions are available in the lab link.
====
